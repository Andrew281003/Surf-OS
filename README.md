# SurfOS Cosmos edition

A bootable x86 operating-system kernel built with Cosmos Gen3. This branch contains the Cosmos kernel, build and VM scripts, and Cosmos documentation.

## Build

```powershell
./scripts/Build-SurfOS-Cosmos.ps1
```

See [architecture](docs/cosmos-architecture.md), [migration notes](docs/cosmos-gen3-migration.md), and [roadmap](docs/cosmos-roadmap.md).
