# SurfCloud publisher

The package, theme, and music catalog publisher for SurfOS. This branch contains the Drive publisher, tests, Firebase configuration, seed data, and operational documentation.

## Build and test

```powershell
dotnet build src/SurfCloud.DrivePublisher/SurfCloud.DrivePublisher.csproj
dotnet run --project src/SurfCloud.DrivePublisher.Tests/SurfCloud.DrivePublisher.Tests.csproj
```

See [repository documentation](docs/surfcloud-repository.md) and [Google Drive setup](docs/surfcloud-google-drive-setup.md).
